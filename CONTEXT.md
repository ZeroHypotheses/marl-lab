# Domain glossary

## Experiment

A self-contained piece of the human's hands-on work, stored in
`experiments/<nn>-<slug>/`. It starts from a question or expected result,
contains the smallest runnable code needed to investigate it, and records what
was learned. **Exercise** is a conversational synonym: local exercises are
stored as experiments rather than in a separate hierarchy.

## Upstream exercise

An externally authored curriculum artifact under `upstream/exercises/`.
Upstream exercises are read-only for agents and use the hint-first workflow in
`workflows/exercise.md`.
