# marl-lab exercises

Small implementation exercises created between reading sections. Unlike
`upstream/exercises/`, these are local to this learning lab.

Each exercise keeps the learner-facing starter in `problem/`. Solutions are
not checked in by default: the human writes the implementation, and the agent
provides escalating hints under `workflows/exercise.md`.
